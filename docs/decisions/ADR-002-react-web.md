# ADR-002 — React + TypeScript untuk Web

**Status: Diterima [DISEPAKATI]** | Tanggal: 23 November 2026

## Konteks
Web dipisahkan dari backend dan digunakan untuk meninjau flow operasional.

## Keputusan
Gunakan React + TypeScript untuk aplikasi web.

## Konsekuensi
UI web tidak berbagi rendering dengan GPUI; kontrak API dan domain semantic perlu konsisten.

## Batas keputusan
Rincian kebijakan produk, API dan skema yang dahulu belum diputuskan kini ditetapkan oleh ADR-007 beserta API_SPEC dan ERD. ADR ini menjadi catatan keputusan teknologi dan tetap tunduk pada baseline terbaru tersebut.
